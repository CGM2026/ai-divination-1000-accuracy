# AI占卜：1000例准确度验证

作者：**长庚明** · 公众号：**明语星辰**

AI Divination · 1,000-Case Accuracy Evaluation

AI用随机抽出的三张扑克牌预测生活故事的结局，能有多准？本项目公开1000例模拟故事的对照检验，以及此前的符号探索、百例试验、解读方法和复现代码。实验先探索花色与牌值，再固定方法，比较“随机三张牌＋背景”和“只看背景”的预测表现。

**千例结果：有牌704/1000（70.4%），无牌691/1000（69.1%）；净差13例，配对精确检验p=0.213153。现有结果尚未建立稳定的有牌优势。**

这是2026年10月15日完成的模型模拟研究。故事由模型预先写定结局，预测也由模型角色生成。完整材料包括834轮探索、1100个故事和2200条原预测。

## 三分钟开始

需要Python 3.10或以上；以下命令只用标准库，无须安装依赖、配置模型或联网。

```bash
python lab.py verify-package
python lab.py reproduce --output runs/reproduced
python lab.py demo --root runs/offline-demo
python -m unittest discover -s tests -v
```

`reproduce`重算百例全部、百例40题留出及千例成绩，并校验原始千例封存记录。输出在新目录的`summary.json`和`report.md`。

`demo`用4道人工固定标签和答案跑通完整工具流程，外部模型调用为0。它演示抽牌、提交、封存和评分，结果不计入研究，也不模拟AI预测能力。

输出目录须为空。重复验证可换新目录。Windows中如没有`python`命令，可用已安装Python的完整路径替换。

| 目录 | 内容 |
|---|---|

## 开展新实验

可手写故事与预测JSON，也可通过可配置的Chat Completions兼容接口生成。新实验模板是本次开源整理新增，历史实验使用Codex多对话分工；模型输出重跑会有差异。

详细步骤见[新实验操作](docs/new-experiment.md)。接口调用由操作者主动发起，可能产生服务费用。凭据从环境变量读取，运行输出默认不纳入Git。

## 研究口径

第一轮468轮＋预试6轮＋第二轮360轮，共834轮。百例前60题分批迭代，后40题留出；随后利用旧材料重新定义5—9，形成2.0，再做1000个新故事的固定方法测试。

原抽牌为系统随机，无种子。重放原实验使用已保存的牌序；新工具另提供`--seed`。原角色共用文件系统，隔离依靠读取约定；本工具同样由操作者管理角色与结局的访问权限。历史配置能核实的部分和缺失项见[提示词与模型来源](docs/prompt-provenance.md)。
