# 数据与方法版本

## 数据

JSONL为UTF-8，每行一条记录。案例编号贯穿故事、牌序和两组预测。

故事必需字段：`id`、`domain`、`background`、`question`、`deadline`、`yes_definition`、`outcome`、`ending`。`outcome`只允许整数0或1；新实验另需`source_type`和`source`。历史百例的`split`区分development与holdout。

两组预测共同字段：`id`、`prediction`、`p_yes`、`answer`。`prediction`为整数0/1，并与`p_yes >= 0.5`一致。有牌千例另有原牌、三张具体翻译与组合句；无牌含`rationale`。百例保留早期格式，主要是整组`rationale`，不伪补当时没有的逐张字段。

千例中一般花色义和数字义由辅助程序统一填充；具体翻译、成句和判断由预测角色逐例生成。一般义一致本身不代表推理来源一致。

探索记录834条使用公开编号E0001—E0834，并保留`original_id`、阶段、原日志位置、问题、牌与笔记。原事件日志为19份：第一轮3份、预试1份、正式第二轮15份。探索牌码C/D/H/S分别为梅花/方块/红桃/黑桃；A、2—10、J/Q/K为牌值。第二轮显示问句后经措辞澄清，改写对照单列，原日志仍保留原问。

## 版本

| 版本 | 含义 |
|---|---|
| `pilot-1.0`至`pilot-1.2` | 各用于20题开发测试，反馈后逐次修订 |
| `pilot-1.3` | 后40题留出使用的方法 |
| `evaluation-2.0-frozen` | 5—9重定义后、千例预测前固定的方法 |
| `post-test-skill` | 千例结束后补成绩与案例说明的Skill |
| 教材 | 当前40个原预测正确的选例；措辞为反馈后的教学整理 |

现行教材将7简写为“差异与例外”，历史方法文件保留当时原话。按版本阅读，不倒写到早期记录。

## 数据转换

公开整理版按字段重排JSON/JSONL，并移除本地路径和会话标识。来源与公开文件的哈希对应见`provenance.json`；最终分发文件哈希见仓库根目录`manifest.json`。

千例冻结ZIP保存原始运行目录及原清单。百例原结果另存`archive/pilot-100-results.json`，规范化数据将公开题面与原预测按S编号连接。结构化抽取和后续删改不计为新增样本。

第三方原书、微信附件、其他案例库和完整本机对话日志未进入此包。故事人物和结局均为实验中的模拟内容。
