# 公开包整理规则

只收录本次扑克牌实验。原案例库、微信资料、私人会话、账号凭据和第三方书籍附件不进入公开包。

`provenance.json`记录历史文件的来源、原文件哈希和公开文件哈希。公开文本删除本机路径与会话标识，改写本地链接；数据中的原判断与结局保留。结构化JSONL是从原记录导出，字段说明见[方法与数据](data-and-methods.md)。

`archive/evaluation-1000-frozen.zip`按原字节保存千例运行目录及其封存清单。解压后仍可用原封存哈希核对，不重新生成历史封存证据。原评分程序另存于`archive/code`。

`archive/exploration-history`保留早期探索协议、阶段笔记、研究者报告和抽牌程序。历史脚本依赖当时目录，公开版的本机路径已删除；直接运行实验使用仓库根目录的新入口。

`src/cardlab`在原工具上增加任意样本数、可选随机种子、统一入口及可配置模型接口。新接口模板与可恢复的历史提示词分开保存。新增内容不能补足历史模型参数的缺失。

教材只保留40个原判正确的选例；完整数据保留正确与错误两类预测。数据报告与教材分别存放。

`manifest.json`覆盖交付文件，排除自身、运行产物、缓存、Git元数据和`verification`检查输出。它用于检查公开包是否变化；历史封存验证另行执行。修改材料后应更新清单，不能据此改写原始实验哈希。
