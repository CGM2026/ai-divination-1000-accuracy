# 扑克牌语言实验：过程与核心结论

本实验尝试把扑克牌当作一门语言：从生活情境出发，用随机三张牌组织描述，再检验它能否帮助预测结果。

## 实验怎样推进

| 阶段 | 做了什么 | 得到什么 |
|---|---|---|
| 探索符号 | 第一轮468轮、预试6轮、第二轮360轮，共834轮。每轮提出情境、程序抽三张牌，再解释与比较。 | 逐渐形成花色、牌值和组合的候选含义。常说的“360轮”特指第二轮正式探索。 |
| 百例试验 | 作者预写100个生活故事及结局。前60例分批预测、反馈、修订；最后40例使用冻结方法。同时设置只看背景的无牌对照。 | 有牌65例正确，无牌69例正确；最后40例分别判对26例、29例。 |
| 固定方法 | 回看旧材料与错例，重新区分5—9，整理讲义并形成Skill 2.0。 | 花色提供观察角度，牌值细分关系，三张牌连成一句话，再给明确判断。 |
| 千例检验 | 三位作者预写1000个新故事，审查问题与结局；固定方法后抽牌。两路各提交1000条预测，全部封存后评分。 | 有牌704例正确，无牌691例正确。 |
| 复盘与来源审查 | 对照原预测、结局与后来的解释，审查词义形成及外部知识影响；最后重写为40例讲义。 | 明确哪些是早期观察、后续定义、预测判断和反馈后的教学改读。 |

两次正式测试合计1100个模拟故事、2200条预测。作者先写结局，预测者按分工只读题面；各角色共享文件系统，隔离依靠读取约定。故事作者与预测者使用同类模型，成绩对应这批模拟题。

## 最核心的观察

### 1. 这套语言擅长把关系分开

四花色逐步形成四个观察角度：方块看东西与成果，梅花看行动与接续，红桃看需要与接受，黑桃看条件与规则。

同一件事可以从不同角度说：东西寄出与对方收到，愿意帮忙与实际帮成，数量足够与用途合适，各自有不同含义。三张牌的教学价值，集中在让这些区别变得清楚。

### 2. 牌值是逐步建立的工作定义

A、2、4、10及人物牌较早出现了可延续的读法，5—9的区分经历了更多修订。现行的5调整、6适配、7差异与例外、8展开、9够用，是结合旧材料和已知反馈整理出的定义。

这些定义能用于组织描述，具体数字与词义之间的独特对应仍待检验。尤其5与7、8与9，在部分情境中存在重叠。

### 3. 主要推理跳跃发生在“关系”变成“未来事实”的地方

常见错例把“可以补救”接成“会去补救”，把“愿意帮助”接成“能够解决”，也会把一项困难扩大成整件事失败。两路预测都偏向判断“会”：千例中，有牌205次判会而未成，91次判不会而达成。

读牌需要识别关系；预测还须判断这些关系接下来会怎样变化。这是两个需要分别评价的能力。

### 4. 复盘改善了讲解，原预测成绩仍按原话计算

知道结局后，常能把三张牌解释得更贴切。这样的改读适合教学，预测成绩则来自揭晓前封存的判断。来源审查还发现，个别早期复盘误述了原来的错因，回查时应以原预测为准。

## 检验得到的结论

| 千例结果 | 有牌 | 无牌 |
|---|---:|---:|
| 正确率 | 70.4% | 69.1% |
| 仅本组判对 | 53例 | 40例 |

有牌净多判对13例，相差1.3个百分点；配对检验p约0.213。**本轮尚未建立稳定的有牌预测优势。**旧百例与新千例使用不同题目及阶段版本，两批成绩分别评价。

来源方面，记录显示心形、人物牌、数字常识等既有知识参与了联想，文学与语言理论也进入了后续阐释。可见日志未发现研究时直接查询或引用传统占卜牌义的证据；与既有牌义的部分相似，因果来源仍未确定。

**目前最明确的成果，是一套能够讨论、教学和继续检验的符号描述方法。它的预测增益，以及各数字含义的独特性，仍是下一步要回答的问题。**
