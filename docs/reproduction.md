# 复现指南

## 1. 核对已有结果

在仓库根目录执行：

```bash
python lab.py verify-package
python lab.py reproduce --output runs/reproduced
```

第一条逐文件核验公开包清单，清点834轮和40例教学选例。第二条读取逐条故事与两组原预测，重新计算正确率、Wilson区间、Brier分数、配对表与精确McNemar检验。

预期结果：百例全部65/100与69/100；百例40题留出26/40与29/40；千例704/1000与691/1000。千例配对表为同时对651、同时错256、仅有牌对53、仅无牌对40。

工具还在临时目录解开`archive/evaluation-1000-frozen.zip`，用其中原始冻结清单检查文件。ZIP内保留原文件字节；公开整理版的文件清单另存`manifest.json`。

## 2. 重放旧实验

使用保存的题面、原牌序与对应冻结方法，重新向模型提交问题，另存新预测，再同原预测比较。已公开的题目和结局适合做流程重放；重新生成的回答不覆盖历史文件。

千例测试前的方法在`methods/evaluation-2.0-frozen`。测试后Skill增加成绩与复盘，当前教材又改过措辞，三者分别保存。

原系统随机没有种子，原牌序依靠记录恢复。API模型的更新、调用参数及上下文变化也会影响回答，历史模型配置的缺失项列在`prompt-provenance.md`。

## 3. 开展新实验

另写故事、预先固定结局，冻结方法后抽牌，分别生成两组预测，全部封存后评分。详见`new-experiment.md`。

建议把作者、预测者与结局文件分配到独立工作区；模型调用入口只传相应公开题面。程序校验哈希会读取文件字节，方法上的盲测仍依赖操作者正确分配材料。

## 环境

核心与重算只需Python标准库，最低Python 3.10。Git工作流会在多个Python版本运行检查。本次实际执行环境记在`verification/acceptance.json`。

PDF随包提供。教材排版源是Markdown；本工具不包含依赖本机中文字体的PDF排版流水线。
