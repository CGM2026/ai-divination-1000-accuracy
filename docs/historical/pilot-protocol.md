# 100例模拟：开始前固定的方法

用户于2026-10-15批准：三张随机扑克牌占卜技能，100个虚构生活故事，作者与预测者分开，60开发/40留出，不抽牌对照。

故事作者先写定100个背景和结局，冻结SHA256。预测者只能读取公开背景。角色使用独立上下文和明确文件访问范围；同一机器文件权限没有物理隔离，审计依据角色指令和实际工具记录，不能称为安全沙箱隔离。

前60例分为三批20例。v1.0预测1—20后评分，只将这一批反馈用于方法修订；v1.1预测21—40，修订为v1.2；v1.2预测41—60，完成一次最终修订后冻结v1.3。每次修订保存原版、依据和变更；没有错误证据时可以保持规则但记录版本冻结。61—100由新上下文使用最终版本一次提交，不再调参。每例只抽一次，结局不改变，预测不重写。

独立不抽牌角色读取同样公开背景、问题与期限，不看牌、牌义、结局和预测者判断；保存二元判断、p_yes和理由。全部100例对照在揭晓结果前固定。

主指标：prediction == outcome 的比例，开发各批及合计与留出集分别报告。prediction只能0/1；遗漏或拒绝判断按错误计并报告。p_yes用于Brier均方误差，越低越好；0.5及以上对应1。主指标采用问题预定的yes_definition，不按叙述“差不多”宽松给分。答案过程和细节另作质性比较，不计入命中率。

留出集比较：抽牌与不抽牌的准确率差、两者各自独对的数量；Wilson 95%区间仅描述本组虚构样本的抽样不确定性。100例非真实世界随机样本，同源语言模型的创作/预测偏好可能影响结果，不能外推真实占卜准确率。50%只是均匀猜测参考；另报留出集多数类别比例作为事后描述参考。

结论不预定成功或失败。若无增益，如实报告，不通过继续窥看留出集改规则来追逐高分。之后的新一轮需要新故事和新的留出集。

执行中补充（前40例预测已提交，后60例尚未预测）：独立结局核对角色不读取预测，报告3例有歧义。主指标保留全部冻结标签；另行报告排除独立审核疑点后的结果。此补充在主角色读取疑点ID和内容之前固定，作者结局保持原样。
