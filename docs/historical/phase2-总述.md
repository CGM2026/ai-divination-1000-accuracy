# 扑克牌诗性语言：第二轮研究总述

本轮形成了较丰富、能够继续使用的花色关系和组合阅读方法。最清楚的成长，是先认出“这一份”由什么用途划定，再检查某段关系怎样接续、怎样照应、依什么条件成立。十三种牌值的成熟程度不同：A、2、3、10已有较清楚的问法，4和6有若干具体桥梁，5—9的独立质地及Q/K的区别仍薄。

这些结果来自五批360轮正式随机阅读、十五个独立研究聊天、四十五份阶段快照，以及另行计数的旧例重读与应用观察。三份核心文稿分别展开[四种花色](phase2-四种花色.md)、[十三种牌值](phase2-十三种牌值.md)、[组合与应用](phase2-组合与应用.md)。它们保留研究如何改变理解，也保留没有长成统一含义的尝试。

## 已经长出来的关系

方块由钱物交换扩到位置、版本、副本和一处可核对的状态；梅花由接着做扩到暂停、分支、退出和关闭提示器；红桃由贴合承接扩到留距离、拒绝本次、局部让声与照顾未来使用者；黑桃由边界限制扩到保护权限、维持间隔、界定共同约定和检查条件。四种花色可以进入同一件生活，区别在于实际着力点，生活领域没有被它们各自占有。

A最有力量的修订，发生在布片与盒口：总面积足够，当前却没有能盖住的一整面（B02-B-R011）。后来“一份”又进入连续安静、完整一句、独立副本与一条入口。10则越来越需要给覆盖范围起名字：归位、维修、答复、交接、计划、实际执行可以分别结束。B04-A-R011让A与10围绕同一次帮问工作，说明单位与覆盖可以同样小，也可以同样完整。

组合的方法比部分单值更成熟。同值换花可以保留比较尺度，也能将同数的不同角色并排：每套两页与打印后余两页是两个2，却不是同一个对象（B05-A-R021）。同花换值可以伸缩注意；交叉重复可以让一张牌同时参加两条线；顺序是一条观看路线，同时看则能保留并存状态。首尾相同没有保证回程，中间也不必成为障碍或桥梁。

人物牌的操作、审看、顾全可作为问法交流。J可以由人或工具承办，Q可以审看规则本身，K可以由共同规则承载。一人可以做几种工作，多人也可以共同承担同一种职能。Q与K仍共享整体审看，现有材料不足以固定分工或等级。

## 研究怎样进行

正式使用法式52张牌，无大小王。每轮先保存原问，再从完整牌组用Python系统随机源抽三张，轮内不放回、轮间恢复，保存实际顺序；研究者看到当前输出后写自然阅读和研究栏，保存成功才进入下一轮。每八轮冻结一份快照。问题、抽牌、笔记共形成1080条顺序事件；360轮共1080张牌次，52张具体牌均曾出现，频次仅作描述。

第一批三组互不读取。第二批起有意继承中央的候选视角，再在新场景中修订，因而后批趋同不能称独立发现。中央逐批亲读阶段快照和代表原始记录，先综合，再选后批问题。每批72轮，分别为基础生活关系、三条关系深化、组合、进入新场景、关键缺口。具体过程见研究过程阅读版。

第三批每组重读三对既有案例，共九次成对比较、十八次源记录阅读，没有新增抽牌。第四批每个新研究者先读三个完整场景与实际牌面，冻结初读，再做24轮新研究，最后回看第一例，共九次初读、三次回看。这些阅读均独立于360轮计数。

三个应用者能使用说明，也能具体指出其薄处。门口例使Q/J成为同一人的看与做，A仍需命名单位；共读收尾例可以明确时限与留存，却不能使6自然等于“细节够”。擦窗回看分别修订了离开前应做多少、下次所需条件如何交清，以及邻近数字是否真的增加理解。可交流性体现在能用、能批评、能修改，不以说出相同答案为标准。

## 五方面评价

| 方面 | 本轮已经支持什么 | 仍需什么 |
|---|---|---|
| 具体 | 阅读能回到移动、拿还、分组、回告、打开文件、换气、关闭提醒等动作。 | 额外设想继续明确写成可能；数值联系需要逐段说明。 |
| 丰富 | 四花色、单位、范围和组合有跨实物、沟通、数字物件、声音及共同规则的表现。 | 检查宽义是否让几乎一切都可被套入。 |
| 有区别 | 单位与覆盖、数量与序位、同数不同角色、计划与执行等区别清楚。 | 5—9及Q/K的独立贡献仍不足。 |
| 能延伸 | 新场景使旧理解真实改变，如复制不减少原件、共同一句容纳局部错开。 | 用固定条件的比较检验具体差别。 |
| 能交流 | 三个新上下文能应用阶段说明，留下九次初读与三次有依据的回看。 | 尚需不同背景的人类读者及实际使用反馈。 |

第五批没有补齐一套整齐词典。数值可以指认真实数量、参与分组、借相邻关系提出方案，也可能因任意换单位而显得总能吻合。B05-A-R024中梅花2引出两回方案，实际房间容量仍是三回；保留二者的差别，是本轮获得的具体方法。

## 材料的性质与核验范围

所有日常情境都是研究设定，未读取微信、私有案例或真实账户内容，也未采集现实行为结果。研究者是使用同一指定模型的新聊天上下文，具有模型既有的语言和文化知识；“陌生符号”是本次任务的处理方式，并没有消除既有扑克图形常识。任务禁止导入既成占卜对应表，六轮预试只用于中央方法校准。

中央请求模型为gpt-6-astra/high，研究聊天请求gpt-6.1-sol/medium，创建工具接受这些请求。回执提供聊天ID和host，没有独立运行时模型遥测。工具只给牌名和顺序，没有统一印刷牌图；对点数、轮廓和布局的联想按常识或记忆记录。

程序检查覆盖牌组合法性、日志链和保存顺序、轮内互异、快照、共同题、来源及显式牌序。部分真实工具轨迹另经抽查，显示当前抽牌输出先返回，后续命令再写笔记。哈希链和快照摘要能检查记录是否改变，不能证明全部思考过程。解释质量由中央按上表阅读判断，用户正文验收尚未发生。详情见最终交付核验及来源复核与勘误。

原始事件和冻结快照保留原样，修订另记。早期把7的奇性评价得偏强、把近似牌列误说成同牌换序，以及几处把可能写得像事实的问题，都保留了原文和后续处理。它们是过程的一部分，不能只留下最后流畅的说法。

## 为什么在360轮结束

五批任务与应用观察已经完成，主要关系已有足够材料展开，剩余缺口也已具体。继续随机换生活问题，未见清楚理由期待它自动分出5、7、8、9或Q/K。更有用的下一步，是固定已有题目做明确标注的遮值、换值比较，或让未参与者实际使用说明并记录误认；这些尚未执行，见[开放问题](phase2-开放问题.md)。

本次交付为研究文稿和完整本地材料包。教材与PDF留待这些认识经过讨论；远程发布平台及许可证未指定。全部原问、实际牌面、笔记和源路径可由来源索引回查。
