# 批量检验规范

记录来源类型。真实事件须有出处、时间及结果证据；虚构故事标为模拟。背景只包含提问时可知信息；结局单独保存。不得把虚构材料称真实发生。

开始前冻结题目、结局、标签、方法版本与抽牌规则，保存SHA256及时间。案例ID唯一，数量和排除规则在揭晓成绩前确定；同故事改写不能当成多个独立事实。

作者/整理者掌握结果；有牌预测者只读公开题面、Skill和抽牌；无牌对照只读相同公开题面；评分者等待两组全部预测提交冻结。角色须独立上下文，共享文件系统时只可声称按读取约定隔离。

共同预测字段：id、prediction、p_yes、answer。有牌另存version、cards、translations（三张分别有card、suit_meaning、value_meaning、context_translation）、combined_sentence；可另存rationale、uncertainty、target_check。无牌对照必存rationale。必须实际逐例推理，不能根据结局、随机标签或机械规则伪造预测。

结局审查只看故事与标准，不看预测。可疑项先标记，报告全量和按预定规则排除后的敏感性分析，不为提高成绩改标签。

全部预测封存后报告：正确数/总数、准确率、Wilson区间、Brier分数、分主题成绩、正负结果分布、无牌基线和配对差异。案例来源依赖与重复模板应另行报告。

方法复盘另存；改进后升版本，需新样本检验。此前100例及讲义案例均已见结果，不混入新的1000例未见结果测试。历史模拟测试65/100、无牌69/100；该混合开发成绩不是当前2.0的验证成绩。
