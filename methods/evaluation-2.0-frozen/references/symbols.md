# 花色、十三种牌值与组合

本表取自本轮讲义，作为2.0工作定义。数字结构不能独自保证某种结局。

## 一、花色：先说清楚这张牌在谈什么

四种花色可以当作四类日常词语。把它们放进问题里，先找到具体的人、东西、行动或要求。

| 花色 | 白话含义 | 读牌时问自己 |
|---|---|---|
| 方块 | 有形的东西、材料、位置、成品 | 实际有什么？最后拿到什么？ |
| 梅花 | 做事、联系、交接、继续行动 | 谁在做？下一步怎样接上？ |
| 红桃 | 想要、喜欢、接受、适合、照顾 | 谁愿意？适不适合这个人？ |
| 黑桃 | 条件、规则、限制、验收 | 必须满足什么？哪一步过不了？ |

例如“红桃＋6”：红桃讲人的接受，6讲配合，合起来就是“人与方案相配”。放进投稿情境，可以说“编辑觉得稿子合适”；放进课程情境，也可以说“参与者与安排需要配合”。具体对象由问题确定。


## 二、组合：让三张牌说同一件事

读组合时，把三张牌写成有主语、有动作、有条件的一句话。

| 组合 | 怎样连成句子 |
|---|---|
| 三张同花 | 同一个方面分三步讲。例如三张梅花：整体安排→重新协调→改走另一条路。 |
| 两张同花 | 比较同一方面的不同层次。例如红桃6与红桃8：某个人觉得合适→放进更大范围后是否仍合适。 |
| 三种花色 | 让不同方面互相作用。例如已有地点→调整要求→家人愿意配合。 |
| 首尾同花 | 说清中间怎样影响首尾。例如成品要求→参与者配合→设备安排。 |
| 同一个牌值、不同花色 | 同一种职能落在不同对象。例如黑桃Q检查规定，红桃Q考虑人的接受。 |

三张牌没有固定的“过去、现在、未来”。最后一张也不自动代表必然结局。读到J，先说谁执行什么；读到10，先说哪一件事需要做完整。


## 三、牌值：同一种花色，为什么还要分数字

花色决定谈哪个方面，牌值决定这个方面以什么结构出现。本稿沿用此前复盘的工作解释，5—9的区别尤其要用句子说清。

| 牌值 | 白话含义 | 放进句子里的用法 |
|---|---|---|
| A | 这一件、这一次 | 先圈定我们到底在问哪件事。 |
| 2 | 两边对照、相互连接 | 这边给出的，能否对上那边需要的？ |
| 3 | 第三方或第三个环节加入 | 除了双方，还要谁参与、哪一步接上？ |
| 4 | 支撑和安顿 | 有个能用、能待、能维持的基本安排。 |
| 5 | 调整 | 原办法不合适，改一下做法、时间或分配。 |
| 6 | 配合与对应 | 人、物、时间、标准能不能搭在一起？ |
| 7 | 个别差异、另行处理 | 这一项有特殊情况，不能照常一起处理。 |
| 8 | 展开和连带 | 一处变化会影响更多部分，要放大范围看。 |
| 9 | 整体够用 | 把已有内容合起来，是否足以承担完整用途？ |
| 10 | 约定范围内做完整 | 原来答应的项目是否全部结束？ |
| J | 执行者或执行动作 | 谁实际办理、制作、交付？ |
| Q | 检查与安排 | 谁判断合不合适，怎样安排？ |
| K | 整体统筹 | 谁掌握整个范围，决定怎样处理？ |

5与7的区别：5是“改办法”，7是“有一项要另办”。6与8的区别：6看两项能否配合，8看扩大范围后出现的连带关系。9与10的区别：9问“整体够不够用”，10问“约定是否全部做完”。这些结构可以用于成功，也可以用于失败；不能仅凭数字给结局盖章。


## 四、综合运用：逐张解释，再把整句话对准问题

按下面的顺序读，每一步都用日常话说清：

1. 先圈出原题要求：谁、什么东西、哪一次、何时以前、多少才算完成。
2. 每张牌分开解释花色与牌值，再说它们在本题具体指什么。
3. 用“先……再……”“虽然……但……”“只有……才……”把三张牌连成一句话。
4. 回答原题，再与结局核对。读错时找出跳过了哪个条件、混淆了哪个对象，改写整句。

要作定性回答，就明确说这次结果是成还是不成；理由也要精确。不能用“活动办了”回答“指定的人到场了吗”，也不能用“东西交了”回答“交的是合格版本吗”。


J/Q/K是职能，不限定性别、年龄或身份；可以由同一人承担。实际数量按背景计算，不能凭5推五天、凭6造六个人。数字递增不自动代表进展，递减不自动代表失败。
