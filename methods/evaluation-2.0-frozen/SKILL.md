# 三张扑克牌占卜

版本：2.0。先读[花色、牌值与组合](../post-test-skill/references/symbols.md)。讲解或复盘时读[案例](../post-test-skill/references/review.md)；批量实验读[检验规范](../post-test-skill/references/evaluation.md)。本版整合360轮探索、100例测试和40例讲义复盘，预测表现待新测试检验。

## 确定任务

- 情境解读：请用抽到的三张扑克牌，描述并解释给定情境。
- 预测：结果未知，回答明确期限内某事会不会发生。保留人物、对象、版本、数量、持续时长与达成标准。
- 复盘：使用原抽牌、原判断与反馈，不再抽牌；解释错误，另写修正解读，保留原评分。

## 执行步骤

1. 保存background、question，可加deadline、yes_definition。期限缺失且影响判断时询问。
2. 执行 `python scripts/draw.py --input 输入.json --output 抽牌记录.json`。52张无大小王，无放回抽三张；重复调用返回原牌，不因难解重抽。
3. 逐张翻译：**花色一般义＋牌值一般义→本题具体所指**。三张都写。5—9使用本版定义，不再一律跳过数字。先从背景找具体对象；新增后续标为预测，不伪装成已知事实。
4. 连成一句话：用有主语、动作和条件的日常话说明三张如何相互影响。可以用“先……再……”“虽然……但……”“只有……才……”。不用抽象名词堆成答案。顺序是阅读路线，没有默认过去、现在、未来牌位，末张不自动裁决。
5. 回答原题：明确“我判断会／不会”，并解释组合句为什么支持判断。允许判断错误，不用相反结局包揽命中。强事实和算术优先，不以牌推翻已知事实。
6. 保存prediction=0或1、p_yes（0至1，0.5及以上判1），以及期限和达成标准。概率是主观把握。日常正文可用低/中/高把握；实验必须保存数值。

## 必须分清

愿意帮助不等于实际到场，喜欢方案不等于最终选择，受理不等于批准，计划备用不等于已可使用。“尚未确认”也不是“已经失败”：判断现有条件能否调整后满足标准，再作单一预测。

复合问题逐项检查：获批且实施、到达且住满七晚、全员完成、正确版本且足额交付。替代人、替代作品、换地点或线上解决，只有原题允许才算同一结果。

5调整，6配合，7个别项另办，8展开连带，9整体够用，10约定范围做完整。它们没有固定成败方向。J是执行职能，Q是检查安排，K是整体统筹，也不能单独保证成功。

## 回答格式

**判断：** 一两句明确回答。

**抽到：** 按程序顺序列牌。

**逐张翻译：** 例如“红桃讲人的接受，6讲配合；在这里是编辑觉得稿子合适”。其余两张同样说明。

**连成一句话：** 把三张连成完整白话句，再解释它怎样支持本次判断。

**核验：** 期限、达成标准及一个关键未决点；实验另存概率。

复盘增加**当时判断、反馈、本次修正**。教学每例必须完整提供背景、问题、牌序、逐张翻译、组合句与反馈。行动建议另列，不能暗中变成预测成立条件。

## 复盘和实验

原判断与新解释分开。反馈新增的事实注明来源；事后能解释不等于事前唯一可预测。无法解释的部分保留，不为了贴答案改词典。每批测试先冻结方法与结局，预测者只读公开题面、固定方法和抽牌；全部预测冻结后评分，与无牌对照比较。详见检验规范。
