# 花色、牌值与组合

## 四种花色

| 花色 | 主要视角 | 预测时追问 |
|---|---|---|
| 方块 | 可指认、分配、交付、核对的一份；物件、位置、版本、凭据 | 目标是否真正落到明确对象与接收处？ |
| 梅花 | 路径、连接、承接、操作与后续 | 下一步由谁或什么接上？暂停或退出是否反而使路走通？ |
| 红桃 | 需要如何被接住、适合与照应、给他人留位置 | 接收端能否实际采用？距离、拒绝和错开也可能是照应。 |
| 黑桃 | 条件、边界、限额、有效范围与约定 | 哪个条件决定事情能否成立？限制也可能保护成果。 |

没有吉凶花色。红桃不是必成，黑桃不是必败。它们不是排他的领域，钱也有承接，关系也有边界。

## 十三种牌值

| 牌值 | 可用的理解 | 约束与成熟度 |
|---|---|---|
| A | 本次用途的一份、一次、一个连续窗口或独立入口 | 明确“一”是什么；不等于最小、开端或新机会。较清楚。 |
| 2 | 两端、两种状态、选择或接口；比较各自的角色 | 不自动是两个人、合作或冲突。较清楚。 |
| 3 | 第三作用项、共同尺度、参与位；实际数量或序位 | 第三项须有背景依据，不凭空造第三者。较清楚。 |
| 4 | 框、支撑、可重复的安排；实际四项 | 四边联想可用但不保证稳定成功。中等。 |
| 5 | 可核对的五项/五分钟或同值比较、相邻序列中的位置 | 没有已建立的独立“变化”义。弱。 |
| 6 | 若符合现实，可看2×3或3×2的分组和对应 | 分组可能是提出的方案；不把任意事项凑六条。中等偏弱。 |
| 7 | 有实际对象时比较奇偶、配对、相邻数 | 不自动有余项或未完成；5、9同为奇数。弱。 |
| 8 | 与邻牌比较展开、密度、4到8的倍数 | 现实次数和工作量不由牌生成。弱。 |
| 9 | 与邻牌比较范围、接近某一已定义的全程 | 不等于即将成功或还差一步；10到9未必倒退。弱。 |
| 10 | 把指定的一段范围或过程看全 | 是检查全程的视角，不是已经完成的证据。较清楚。 |
| J | 承办、执行、处理动作 | 可由人、工具或机构承担；没有J也会行动。 |
| Q | 审看、核对、安排、采用者视角 | 不是女性或神秘第三人；与K重叠。 |
| K | 更大范围的统筹与共同规则 | 不必是领导、男性或更强权力；可同一人或集体。 |

## 三张怎样合读

- 同值不同花色：在同一尺度下比较不同对象，也允许相同数字具有不同单位或角色；不要自动“加强吉凶”。
- 同花不同值：关注同一关系的范围伸缩；数列递增不是事情必然发展，递减不是损失。
- 交叉重复：一张牌可同时参加同花线、同值线，分别解释它连接什么。
- 首尾同花：中间可以是对象、索引、观看角度，不必是障碍、桥梁或回归。
- 先按顺序读，再把三张同时看。没有固定末牌裁决法；不强迫每张贡献相等。
- A和10可以看同一小事：定义本次一份，再问这份是否走全。J/Q/K是可重叠职能。
- 算术先按生活单位计算。不能拿牌值制造时间、数量、金额或人数。牌联想新增的后续只能写为预测，不能说成已知事实。

## 从解释走到预测

这些牌义最初用于理解情境，本身没有已验证的“某牌必有某结果”规则。本技能增加的预测步骤是：依据背景提出有限的未来路径，再由符号突出某个承接、交付、需要或条件，选择最倾向的一条。记录选择理由，允许后来判错。不要用宏大、两可句子代替具体事件判断。
