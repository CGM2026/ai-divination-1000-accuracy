## 反馈后的操作要点

以下是本轮案例支持的教学改进，未来使用时照做并保存判断；其是否提高命中仍需新题检验。

1. 每张牌先写一般义，再明确谁、哪件东西、哪一步；数字说明关系，不能直接代替关系的实际状态。
2. 写成句子时核查连接词：从“愿意帮／可以改／有备用”走到“会做成”，中间预测了什么动作？明确说出来，不将建议伪装成已经实施。
3. 保留原题的人、物、数量、版本、地点与时间。另一个人补完、换件物品、局部完成，只有题目允许才算达成。
4. 7指出个别项需要另办，不自动代表失败；5指出调整，不自动代表调对；6要检验两端是否配合；8可描述牵连或扩展，仍要判断实际走向；9问本次整体用途够不够，10核约定范围有没有全部做完。
5. 预测仍然明确选“会／不会”。不以“尚未确认”自动判失败，也不因结局可想象就判必成。
6. 复盘时分别写：原判断、实际反馈、原先已有而忽略的事实、反馈新增事实、修正读法。判断对而原因错，也要说明。

## 八个综合案例

以下案例全部来自本轮1000例。逐张一般义沿用symbols.md，具体翻译与成句是已知反馈后的教学解释。原始答案和评分保留。

### T0031　先把“全部五盆”写进问题

背景：阿越替邻居预约货运车搬盆栽，平台报价含司机协助，但司机短信说不搬带泥物品。邻居楼下有电梯，最重的花盆两人也搬不动，双方还在确认服务范围。

问题：截至2026-11-12，全部五盆原盆栽搬到新住处且盆体无破裂吗？

期限：2026-11-12；达成标准：全部五盆原盆栽搬到新住处且盆体无破裂

原牌序：方块2 → 黑桃2 → 梅花2

原判断：我判断不会五盆全部完好搬到新住处。

原组合句：三重对接都落到最重花盆，司机不搬而两人搬不动会使全量搬迁卡住。

反馈：司机到场仍拒绝搬最重的一盆，只运走其他四盆。临时找的搬运工来得太晚，剩下大盆十二日仍在旧住处。已运四盆都无破损，但五盆全到达的标准没有完成，报价争议也未当天解决。

原评分：正确。

- 方块2：花色讲东西、材料、位置、版本与实际交付成果，牌值讲两端、两边或两种状态的联系与对照。在本题中，五盆原盆栽要从旧住处这一端完整送到新住处另一端。

- 黑桃2：花色讲条件、规则、范围、限制与核验，牌值讲两端、两边或两种状态的联系与对照。在本题中，平台承诺的协助范围与司机实际接受的范围，需要放在一起核对。

- 梅花2：花色讲行动、联系、交接、协作与继续推进，牌值讲两端、两边或两种状态的联系与对照。在本题中，邻居与司机之间必须有人接上最重花盆的搬运动作。

教学成句：五盆都要送到新住处，但平台与司机的搬运承诺没对上，重盆缺少接手搬运的人，最后只送走四盆。

复盘：三个2分别落在运输两端、承诺与执行范围、搬运双方的交接上，并非说只有两盆。背景已经给出司机拒搬与两人搬不动的矛盾，原判断准确抓住它。反馈又确认临时人手来迟。核对时必须同时看“五盆全到”和“盆体无裂”，四盆完好不能代替五盆全部完成。

### T0050　保留原牌，查清从哪里推错

背景：罗遥想制作一张家族关系图送给祖母，已经写出四代二十个人名。两位远房亲戚的排行不确定，姨妈能提供信息但最近忙，图稿周五送印才赶得上周日聚会。

问题：十月二十五日能否送出姓名关系全部核准的成品图？

期限：2026-10-25T18:00:00+08:00；达成标准：二十人的姓名与亲属连线全部经家中知情者核准，打印成品交给祖母。

原牌序：方块8 → 红桃A → 方块7

原判断：我判断不会按时送出全部核准的成品图。

原组合句：整体图已展开，但个别排行还依赖忙碌姨妈，送印前难把所有连线核准。

反馈：姨妈周四晚上语音说明两人的长幼和亲属关系，罗遥修改后把整图发给她与父亲分别复核。两人都确认无误，她周五送印，周日午饭时交给祖母。成品包含全部二十人，关系线也按核准版打印。

原评分：错误。

- 方块8：花色讲东西、材料、位置、版本与实际交付成果，牌值讲向更多部分展开并发生联动。在本题中，四代二十人的姓名与关系线展开成一张相互关联的家族图。

- 红桃A：花色讲人的需要、意愿、接受、适合与照顾，牌值讲一个明确单位、这一件或这一次。在本题中，让祖母收到一张准确的关系图，是这次明确的心意。

- 方块7：花色讲东西、材料、位置、版本与实际交付成果，牌值讲个别差异、例外与区别处理。在本题中，两位远亲的排行与相应关系线，是需要单独核准的个别项。

教学成句：图中两位远亲先得到单独核对，整图再经家人复核，送印后按时作为这次礼物交给祖母。

复盘：原来的三张具体所指基本成立，错误出在把“姨妈忙”直接推成“来不及”。7指出有限的待核项，未规定它们无法解决。周四语音及两人复核是反馈新增的行动；事前可以判断能解决，却不能声称牌已给出这些细节。沿用原牌就能查明这次推断，无须重抽。

### T0037　能替人制图，还不等于能核对数据

背景：实验小组计划做一份十五分钟汇报，三个人各讲一部分。最后一人的数据图尚未完成，组长可代做图但不了解原数据，老师要求每人讲自己的实验结果。

问题：截至2026-11-12，三人均展示经核对的数据并完成各自汇报部分吗？

期限：2026-11-12；达成标准：三人均展示经核对的数据并完成各自汇报部分

原牌序：方块6 → 梅花7 → 黑桃9

原判断：我判断不会三人全部完成合格汇报。

原组合句：组长能帮制图却不熟原数据，特殊一份难完成核对并由本人讲清。

反馈：最后一人只交了汇总数，没有保留部分原始读数，组长无法核对图表。汇报时老师允许前两人正常展示，第三人仅说明进度未展示可靠结果。十二日三人各自完成合格数据汇报的要求没有达到。

原评分：正确。

- 方块6：花色讲东西、材料、位置、版本与实际交付成果，牌值讲对应、配合与相互适合。在本题中，每个人展示的图表都要与自己的原始实验数据对应。

- 梅花7：花色讲行动、联系、交接、协作与继续推进，牌值讲个别差异、例外与区别处理。在本题中，最后一位成员的数据图，需要从其余两份中分出来单独制作和核对。

- 黑桃9：花色讲条件、规则、范围、限制与核验，牌值讲已有内容对整体用途是否足够。在本题中，整组三人都须有可靠数据并完成本人讲解，现有内容才足以满足这次汇报要求。

教学成句：组长能帮最后一位成员制图，却无法补出可核对的原始读数；缺了这份可靠结果，三人全部合格汇报的条件没有满足。

复盘：原判抓住了题面已有的关键差别：会做图与掌握原数据是两回事。6要求对应，7指出个别缺项，9检查整组是否具备足够内容。“部分原始读数没有保留”只在反馈出现，不能说当时已经预见。正确的是对核验缺口的判断，具体缺失原因属于后来确认。

### T0061　“这样做就行”不能替代“她会这样做”

背景：林可报名参加校内口述历史比赛，需要采访一位长辈并提交五分钟录音。爷爷愿意谈旧街道，家中环境常有电视声，林可计划周末采访，手机只剩少量储存空间。

问题：林可能否按时交出清楚可听的五分钟采访录音？

期限：2026-10-26T18:00:00+08:00；达成标准：提交文件可正常播放至少五分钟，爷爷回答主要内容清晰可辨。

原牌序：方块5 → 黑桃A → 梅花7

原判断：我判断会按时交出合格五分钟采访录音。

原组合句：先腾空间并关电视或换安静处，这次采访便能留下清楚足时录音。

反馈：林可忘了清理储存空间，采访到第三分钟手机停止录音，当时只顾听爷爷讲话没有注意。周一整理时才发现文件仅两分四十秒，爷爷已去外地探亲。她交了短片段说明情况，未达到五分钟要求。

原评分：错误。

- 方块5：花色讲东西、材料、位置、版本与实际交付成果，牌值讲调整原有安排，改变一个具体方面。在本题中，手机储存空间不足，需要先清理或调整，才能保存预定录音。

- 黑桃A：花色讲条件、规则、范围、限制与核验，牌值讲一个明确单位、这一件或这一次。在本题中，这次提交的那份文件必须能播放至少五分钟，主要回答还要听得清。

- 梅花7：花色讲行动、联系、交接、协作与继续推进，牌值讲个别差异、例外与区别处理。在本题中，存储不足这个特殊状况，需要在采访操作前另作处理。

教学成句：这次五分钟录音要求先处理存储不足；林可没有做这一步，录制中途停止，提交的短片段未达到时长要求。

复盘：原组合句提出“先腾空间并关电视”，实际上写的是解决方案，题面并未说明林可已经决定并会执行。两路预测都把容易解决的问题当成必将解决。复盘应把“需要调整”与“会去调整”分开判断。失败原因是录音过短，反馈没有说电视噪音造成失败，不能补上这个理由。

### T0038　明确回答原题中的“各自采够”

背景：亲子团报名去农场摘草莓，要求每个家庭都能带回自己采的果子。农场说最近成熟量少，组织者仍按原计划收了十二户，尚未商量分时采摘。

问题：2026-11-22十二户是否都带回至少半斤自己采的草莓？

期限：2026-11-22；达成标准：十二户各自实际采到并带回不少于半斤果子，购买补足不计。

原牌序：方块J → 方块4 → 梅花8

原判断：我判断不会十二户都带回半斤自采草莓。

原组合句：采摘能举行，但成熟量不足又未分时，难让十二户各自采够半斤。

反馈：农场分两棚开放，前八户采够，后四户每家只采到三四两。农场赠送现成盒装草莓补足，所有人带回的总量够，但后四户自己采的数量不足，标准未全达到。

原评分：正确。

- 方块J：花色讲东西、材料、位置、版本与实际交付成果，牌值讲实际执行、办理与操作。在本题中，每户实际动手采下的草莓，才是本题要核对的交付物。

- 方块4：花色讲东西、材料、位置、版本与实际交付成果，牌值讲使事情固定或安顿的支撑安排。在本题中，现成的成熟果量，是支撑各户采摘的物质条件。

- 梅花8：花色讲行动、联系、交接、协作与继续推进，牌值讲向更多部分展开并发生联动。在本题中，采摘行动扩展到十二户，连带增加了必须分给每户的成熟果量。

教学成句：十二户都要亲手采足半斤，人数扩大了对成熟果量的需求；后四户没采够，获赠盒装果也没有完成自采标准。

复盘：原判断明确回答“不会十二户都采够”，没有用“活动仍会举办”回避题目。关键是每户、半斤、自采这三个限制同时成立。反馈中的前八户与后四户把差别落实出来。梅花8说明集体行动牵连的需求，方块4仍须核对资源是否足够，不能只看活动有人组织。

### T0081　同意先结一部分，不是认可完整账单

背景：任琪想把旅行花费整理成共同账单，四人分别有支付记录，其中一人习惯用现金。大家约周日核算，现金支付者说记在小本上但几笔没写具体用途，任琪准备逐项问清。

问题：十一月一日能否得到四人都认可的完整旅行账单？

期限：2026-11-01T22:00:00+08:00；达成标准：全部共同支出金额与分摊对象核实，四人明确确认最终账单。

原牌序：红桃5 → 方块6 → 梅花4

原判断：我判断会得到四人都认可的完整旅行账单。

原组合句：集中逐项询问能补清现金用途，四方记录对应后会形成认可账单。

反馈：大部分电子记录核对一致，两笔现金支出却无法确定是一人消费还是四人共有，相关小票也不见了。大家同意先结清确定部分，把两笔留待想起后再说。二十二点最终账单仍有未决项，没有完整共同确认。

原评分：错误。

- 红桃5：花色讲人的需要、意愿、接受、适合与照顾，牌值讲调整原有安排，改变一个具体方面。在本题中，四人调整了结算安排，接受先结确定部分、暂留争议项。

- 方块6：花色讲东西、材料、位置、版本与实际交付成果，牌值讲对应、配合与相互适合。在本题中，每笔金额都要对应到实际用途和应当分摊的人，两笔现金没有对应清楚。

- 梅花4：花色讲行动、联系、交接、协作与继续推进，牌值讲使事情固定或安顿的支撑安排。在本题中，约定周日集中逐项核算，给共同整理账目提供了固定安排。

教学成句：四人一起核账却没能把两笔现金对应到共同消费，于是接受先结确定部分；完整账单在期限内仍未形成。

复盘：原预测把集中询问当成必能补回用途信息。反馈说明合作确实发生了，但合作没有消除证据缺口。红桃5可描述大家接受调整后的结算办法，不能替全账核准作证。要分别核对“同意先付一部分”和“全部金额与分摊对象核实”，这两种认可的范围不同。

### T0041　结果判对了，也要检查理由

背景：赵灵为弟弟找童年录音磁带，记得标签写着生日歌，家中还有十几盘相似空白带。旧录音机能转但声音偶尔断续，弟弟月底生日，她想先找到对应内容再做礼物。

问题：十月三十日前能否找到并听清那段原生日录音？

期限：2026-10-30T20:00:00+08:00；达成标准：找到原磁带且能完整听清生日歌与弟弟的说话声。

原牌序：黑桃4 → 红桃K → 方块7

原判断：我判断不会在期限前完整听清指定原录音。

原组合句：找出目标带仍要靠断续录音机播放，原歌和说话声难保证全听清。

反馈：赵灵找到标签对应磁带，借到正常录音机播放时发现中间一大段磁层损坏，生日歌只有开头可听。她试着清洁机头后问题仍在，弟弟说话片段始终断裂。原物找到了，但完整听清指定内容未实现。

原评分：正确。

- 黑桃4：花色讲条件、规则、范围、限制与核验，牌值讲使事情固定或安顿的支撑安排。在本题中，借到正常录音机，使稳定播放所需的设备条件得到补足。

- 红桃K：花色讲人的需要、意愿、接受、适合与照顾，牌值讲对整个指定范围的统筹与负责。在本题中，赵灵把寻找、试听和准备送给弟弟的礼物作为一件完整事情来安排。

- 方块7：花色讲东西、材料、位置、版本与实际交付成果，牌值讲个别差异、例外与区别处理。在本题中，找到的目标磁带自身有磁层损坏，需要与录音机问题分开检查。

复盘：原判“不会完整听清”正确，但原组合把原因放在断续的旧录音机上；反馈却说明换好机器后仍因磁带损坏而失败。现在把方块7指向这盘带的特殊损坏，是已知反馈后的重新指认。它可以使解释更贴切，却不能倒算成原预测已看出了磁层损坏。

### T0082　把特殊物件的限制落实到操作

背景：旧物展借来一只台钟，物主要求不能上发条。策展志愿者想让它在开幕时走动，负责人已在借条上圈出禁止上弦，尚未向所有轮班者解释。

问题：2026-11-21展览期间，台钟是否始终没有被上发条？

期限：2026-11-21；达成标准：当天任何工作人员均未给该台钟上弦。

原牌序：梅花7 → 黑桃J → 方块7

原判断：我判断不会全展期始终保持无人上发条。

原组合句：借条虽写明禁令但轮班交代未落实，想让钟走动的操作会触碰限制。

反馈：负责人二十日晚给表冠套了纸封签，并把禁止上弦写进交接表。二十一日一位志愿者询问能否启动，被当班负责人制止。闭馆时物主检查封签完整，台钟始终没有上弦。

原评分：错误。

- 梅花7：花色讲行动、联系、交接、协作与继续推进，牌值讲个别差异、例外与区别处理。在本题中，这只借展钟的操作需要另行交代，轮班交接不能按通常习惯处理。

- 黑桃J：花色讲条件、规则、范围、限制与核验，牌值讲实际执行、办理与操作。在本题中，禁止上弦必须由当班者实际执行，负责人确实加封签、写交接表并制止上弦。

- 方块7：花色讲东西、材料、位置、版本与实际交付成果，牌值讲个别差异、例外与区别处理。在本题中，这只借来的原台钟有特殊使用限制，需要单独照管。

教学成句：负责人把这只台钟的特殊限制落实到交接、封签和现场操作中，全展期都没有人给它上弦。

复盘：原预测从“还没向所有人说明”推到“会有人上弦”，低估了截止前补齐交接的可能。两个7分别指出特殊操作与特殊物件，J强调禁令实际执行。封签、交接表及现场制止是反馈新增的事实；它们展示了达成的过程，原来的未达成判断仍然计错。
