# 扑克牌方法来源审查

审查日期：2026-10-15。范围：最初符号交流、两轮探索、Skill 1.0—2.0、旧100例、新1000例及教材复盘。原资料只读；本目录为独立审查成果。

**结论：这套方法受到了既有文化与牌面知识的影响，也明确借用了网上查阅的文学、语言哲学及语言学理论；不能称为“所有含义完全由随机交流独立涌现”。但是，在本次可见研究日志中，没有找到研究时查询或引用既有扑克牌占卜、塔罗、数秘牌义的直接证据，现有相似性不足以确认具体借用了哪个占卜体系或网页。**

**影响最明确的环节有三个：初期联想借用心形、尖形、人物牌和数字常识；教材阶段主动引入诗学、语言游戏与框架语义；旧100例结束后，模型利用已知场景和错例重新定义5—9，并把新定义用于2.0及千例预测。第三项是可以确认的事后理论建构，不等于已经确认互联网占卜污染。**

最需要收紧的判断是：“有内部举例”不等于“这个含义只能由该数字推出”。5调整、6配合、7例外、8展开、9整体够用都有可指认的旧材料，但材料对数字之间的排他区分支持不足，尤其5/7、8/9可互换。没有证据把这些定义升级成随机符号已经揭示的独特意义。

## 2. 可确认的影响

### 初始联想已有文化输入

第一轮关系第2轮直接写：“末尾9的心形使我感到暖，这是已有的心形常识侵入了实验”；时间第3轮写A习惯被认作第一张，Q带来人物轮廓，来自颜色和字母常识。身体第1轮已有梅花团块、方块尖角与人物站位。第一轮总述也明确说J/Q/K最明显借用了已知人物牌常识。

这些不是审查者猜测，而是当时自述。它们影响了花色感情色彩、人物牌角色及数字顺序感。它们并未注明来自占卜书；心形温暖和国王体量也可从日常文化、纸牌游戏及语言习惯而来。能够确认的是先验参与，不能把来源再缩成“某个互联网占卜体系”。原工具仅返回牌码/牌名与顺序，具体印刷牌点布局并未作为图像提供；所谓疏密、姿态部分来自模型记忆中的牌面，不能当现场视觉观测。

### 联网理论确实进入了教材及后续表达

历史日志中有11条包含web操作的外层调用：第一轮教材5条，千例理论6条；另有2次本机阅读器检查。第一轮查诗学/文学理论，后期查Wittgenstein和FrameNet。不是11个网页，嵌套调用中有多项搜索/打开。

第一轮教材在468轮之后引入诗性观察、比喻与排列的理论讲法，早于第二轮；它可以影响后续主持者的提炼与表达。框架语义和语言游戏在13:09—13:10检索，晚于12:30的5—9重定义；时间顺序排除了“这次新查FrameNet直接生成12:30定义”的说法，但理论研究者后来承担前500有牌预测，故其表达框架并非与预测过程完全无关。具体借用有署名引用，性质是教学和描述方法，不是占卜牌义。详见[历史理论来源与边界](external-references.md)。

### 5—9在知道旧结果后被重新建构

1.0—1.3始终保留5没有独立变化义、7不自动余项、8/9相对比较较强的说明。前60开发例的迭代主要修订成功门槛、未决条件、备用方案及对象验收，没有产生今天的5—9词典。

12:27用户要求仅基于旧数据重新区分数字；12:30模型给出5调整、6配合、7分异、8展开、9整体承载，并说9是本次最需要辨认的新提案。它引用旧场景，也用已知S006和S027错例解释新词义。这是有日志的内部重定义，不是现在审查时补造的来源。

这一步之后，新义进入40例讲义、2.0测试前固定方法。新1000中772例至少有一张5—9，接触了这组新定义。**772是词义暴露例数，不是确认被外部污染或受该词义单独支配的例数。**千例后教材66例则再度知道结局后改读，不能倒过来当成2.0首次含义的形成证据。

## 3. 哪些地方有内部推导，哪些地方仍是跃迁

全部四花色、13牌值的最早片段、演变、外部差异和证据强度逐项保存在[逐项对照表](symbol-origin-table.md)，可机器查的完整原文在同名JSON及逐符号内部证据全集.json。以下集中列出决定结论的薄弱点。

| 义项 | 内部支持 | 推导尚未完成的部分 |
|---|---|---|
| 5调整 | B04-C-R005有调整安静时段；B04-B-R012权限改为评论；B05-C-R024局部修差 | 前者5原本只是五分钟，后者明确不固定5=中转；“局部修差”也可支持7例外。发现共同调整动作，未证明为何必须对应5 |
| 6配合 | B03-A-R010六封信两组三确有数量、分组对象；B03-C-R005需要与动作配对 | 两组三只是部分材料；B04-A-R016六项信息是建议组织出来的，不是题面已有。扩大成任意时间/人/标准配合，专属性下降 |
| 7例外 | 椅子另置、临时柜格恢复、滴水管纠偏，确有个别项 | B02-B-R002六袋米并无奇数余袋；原总结已经撤回强归因。由奇性迁移到一切特殊条件，5/9也可如此；后来用S027失败再定义7不能追认为预测前证据 |
| 8展开 | 多终端共享、四到八动作积累、范围扩大有轨迹 | S006知道整期题材拥挤后才把6/8区分为局部/大范围；替换试验没有建立独占性 |
| 9整体够用 | 归档再利用、纠错留痕及范围检查均有案例 | B04-B-R024原注说同值换花强于9自身；B05-C-R020原注仍说9缺独立数义，且把9说成向后展开，接近后来8。12:30是在这些材料上新提出充分性，不是此前已稳定 |
| J/Q/K职能 | J执行、Q审看、K顾全有门机构、盛面、书角和工具协作等跨场景证据 | Q也能看整体，K也能审查；最早人物体量有文化先验。后期三职工整不能抹去重叠，也不等于照搬侍从/女王/国王的占卜角色 |

因此不能简单判“这些全是凭空出现”，也不能判“只要给出旧例就已排除外部影响”。准确说法是：**有内部材料的再解释与工作定义，部分结构有算术/图形依据，排他映射和预测效应尚未确立。**

## 4. 与既有占卜、塔罗、数解释的对照

本次外部对照覆盖1914年多种扑克牌系统、1902年32张牌法、Webster的花色×数义法、Cafe Astrology站方方法、Waite若干具体单牌，以及Westcott 1911的数字解释。逐项[书目、原文位置、少量引文、访问状态](external-references.md)已分开登记。

关键发现是多重相似与明显差异同时存在：Webster确实用“花色的一般领域×数字的一般义→结合具体情境”的方式，但他的9为利他，10为成熟的新开始，与本项目不同。Warford在1902年已有牌如字母连成词句的比喻，说明语言式合读并非本项目历史首创；这并不能证明本项目读过Warford。Westcott的5质量变化、6和谐、9完满、10全成与项目有近似，而其7神圣与8立方/和谐并非项目的例外/展开。Waite圣杯9可以表示满足成功，宝剑8却偏受限，权杖5偏竞争，不能抽去花色拼成一张“塔罗数字统一表”。

这些外部页面都是本次审查新查。**没有把语义近似直接判成因果抄用，也没有因为未找到引用就判成绝对独立。**尤其5变化、6配合、9/10完整，是应保留来源疑问的重合点；目前证据等级仍是“相似但因果未定”。

## 5. 原预测有没有悄悄恢复常见联想

核对一般义字段发现，千例3000张均使用固定13牌值和四花色词典；但预测工作说明及编码工具明确，一般义由程序统一填充。因此这些一致字段只证明输入/序列化一致，不能证明逐例推理没有旧联想。真正要看具体翻译、组合句和答案。

18个人工核定案例与原错判保存在[受影响案例索引](audited-cases.md)。可以确认两种问题：

一是**描述结构被推成未来事实**。T0025两9加末张10，把需要核对完整计划写成将形成完整确认，实际仍一项待定；T0738的K统筹、J执行被推成原片全找齐，实际旧盘损坏；T0007把检查与配合推成作者将确认。这类读法在形式上接近完成/执行的占卜联想，但本地词典加叙事推进已能解释，无法识别哪个外部来源造成它。

二是**条件容易被读成失败，接受/推进容易被读成成功**。T0008、T0009将条件阻力和例外转为不能完成，实际有可行安排。它们提示要审查负性权重，却不足以宣布“黑桃凶义已回流”。反例T0001末张黑桃9仍判成、T0055末张红桃9判不成、T0027末张红桃K判不成，排除了全程机械黑桃败、红桃吉、末9成的方法。12:24的一次答复把末张红桃4明确说成终点安顿，可确认结果位式读法曾出现，未见其外部出处。

**本次没有确认某例因使用某互联网既有牌义而判定。确认的是存在与传统联想相似的推理跳跃、也有相反案例；其因果来源仍未定。**不能用关键词命中数替代这个判断。

## 6. 教材复盘本身存在归因失真

S081原预测明确写“9不等于临近成功”，主要凭草图获认可而略偏正式交付；复盘却说“原来把草图得到认可与末张9连读成正式采用”。这把新解释投射成了旧错误的具体来源。S095原预测明确说九户报名才是略偏达标的事实依据，复盘则突出“把梅花10读成所有目标都完成”，也省略了原来真实的常识判断链。

这里不能用复盘指控原预测偷偷用了成功牌义。**原预测优先于后来的错因总结。**能提出“若按新9解释可以提醒查完整用途”，与能证明“当时因9成功义而误判”是两件事。旧40例讲义及其进入2.0的复盘材料因此属于已知结果训练材料；新66例仍是教学，不额外验证词义。

## 7. 故事和问法怎样塑造了体系

最早问题围绕身体、关系、时间，由读牌者连续追问。问题提供冷暖、接近、拒绝、开始/结束等方向，随机牌没有给中文纠错。原笔记多次自认先问“残留”才把下降读成退去；这些义项同时来自问题选择、数/形常识与解释者，不能只归给牌。

正式360轮进一步预设杯、面包、权限、归档、接续、数量、核验等主题，并逐批继承候选。它确实有助于本项目发展出“物/操作/需要/条件”的框架，但也意味着题库和后来词典相互适配，不是从无主题随机牌获得独立语义。360条索引后期统一显示了更明确问句，本审查按原events及original_question回看，不把后改措辞当原始提示。

旧100作者记录要求不读Skill/牌/预测。新1000则明确作者及预测者可能知道既有方法：总控兼作者C、原预测角色兼作者B、作者上下文继承，题目反复涉及指定对象/版本、是否全部完成、未决条件、可调整路径。协作总账明认这一点，13:38进度也明确主动设计“东西到但版本不对、指定人没来、调整后成功”等类型。可确认题库受到**本项目已成形的研究与错误分类**塑造。这不等于作者从互联网抄牌义，也不能把新故事称为对本方法全然不知情的外部世界。

先写结局、再抽牌、预测者不看新结局的冻结链，防止了按新牌倒编答案；它没有排除共用模型先验、作者对本地方法熟悉及题目风格与方法之间的关联。1100个都是生活模拟故事，不能据其原分数确认来自现实独立样本的预测效力。此次不重新评分，保留旧有牌65/100、无牌69/100；新有牌704/1000、无牌691/1000，以及原配对检验结果。

## 8. 五档证据结论

| 证据档 | 本次成立项 | 不能由此推出的结论 |
|---|---|---|
| 可确认显式借用 | 教材引用诗学、语言游戏、框架语义；研究者明认人物牌及心形等既有常识 | 引用语言理论即抄塔罗牌义 |
| 有日志接触且后续对应 | 第一轮教材文学理论；13:09后语言理论进入教材和前500预测者上下文；旧数据12:30重定义进入2.0 | 任何相同说法都由那次接触造成 |
| 语义相似、因果未定 | 红桃感情、方块物质、5变化、6和谐/配合、9/10完整、词句式合读 | 单凭相似认定来自某网页或传统 |
| 内部推导可见，不排除既有知识 | 形状/数量/角色联想，6分组，J执行，Q审看，K统筹，5—9重新比对旧例 | 含义由数据唯一推出，或已排除预训练知识 |
| 资料不足 | 不透明调度文本、未留存接触、模型预训练的具体来源贡献 | 没查到日志就证明从未联网、模型没有旧知识 |

当前可以排除的强说法是“全套由零先验纯涌现”。当前也没有证据成立的强说法是“全套照抄互联网某一套占卜牌义”。**最符合证据的定位是：文化先验参与的情境联想研究，经过主持者归纳、已知反馈后的工作定义建构、明确的语言理论教学包装，再被用于固定方法的模拟预测检验。**

## 9. 有依据的修订建议（尚未实施）

1. 在方法来源说明中写清834轮包含468+6+360，分开原始用法、12:30事后新定义、2.0测试前固定、千例后的教学改读；不要把5—9新义追溯成360轮已稳定发现。
2. 将“来源于内部旧数据”与“内部独有、排除既有知识”分开。保留5—9工作定义，但标注区分依据仍弱；尤其5/7与8/9需同场景换牌、遮蔽词典或替换定义才能检验排他性。
3. 修正S081、S095复盘的旧错因归因，原预测照录，另写新读法能提醒什么；不把后来的成功解释当当时隐含推理。
4. 继续保留一般义由程序填入的说明；来源审计和预测审计应读取逐例具体翻译/成句，而不是以字段一致率自证没有污染。
5. 如以后检验独立增量，可用不了解本地词典的故事作者，并预先固定可比较的替换词典/换牌条件。此为新实验建议，本次不启动、不改Skill或教材。
